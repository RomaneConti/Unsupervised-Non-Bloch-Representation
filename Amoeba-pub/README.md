# Amoeba/Ronkin Calculations

Run `run.m` to generate the OBC spectra, minimize the Ronkin function using Jensen's formula, and reconstruct complex momenta. Results are saved under `Revision2_Data/`. Run `RFIG2_Amoeba.m` to reproduce the diagnostic figure (uncomment its data-loading lines first).

Requires MATLAB with Optimization Toolbox, Parallel Computing Toolbox, and Mapping Toolbox. No precomputed data are included; adjust local paths as needed.
